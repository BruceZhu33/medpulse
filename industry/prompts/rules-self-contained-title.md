
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：产品名与型号 / 公司与机构名 / 法规与注册路径名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是代号 / 没信息量的 teaser（如 "我们获批了"、"重磅官宣"、"Day 1"、"喜讯"）时，结合【来源】和正文把主体补进标题。例：原标题 "我们获批了" + 来源 "Boston Scientific 官网新闻室" → "Boston Scientific 产品获批上市"（具体型号以正文为准）。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体型号时，用上位词（如"国产影像设备""人工晶状体"）兜底，绝不凭"行业常识"编一个具体型号 / 注册证号 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review 这类解释、分析、教程或评测标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的产品或新数据，就改写成“发布 / 推出 / 获批 / 上市”。只有原标题明确宣布了发布、推出、获批或上市，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的公司、产品、机构名。
   例：原标题 "How MDR deadlines reshape legacy device portfolios" → "MDR 过渡期如何重塑老产品组合"，不能写成 "欧盟发布 MDR 新规"。
   例：原标题 "How to prepare a 510(k) submission for AI-enabled software" + 来源和正文明确是 FDA 指南解读 → "AI 医疗软件的 510(k) 申报怎么准备"，不能只写成缺主体的 "申报怎么准备"。
